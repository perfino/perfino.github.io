perfino for Mac

Version 4.3. Powerful JVM monitoring for production servers. Gain maximum insight with minimum overhead—directly from your Mac.

Instant Visibility

Log in to see if everything is OK or something is wrong. The dashboard provides fine-grained control over acceptable performance levels, letting you drill down into detailed views effortlessly.

Cross-VM Transactions

Monitor business transactions spanning multiple VMs. Calls from web layers to EJB servers and web services stay connected, even at method-level sampling. View the big picture now or historically.

Intelligent Alerts

React to issues with triggers and actions. Set up alerts, emails, or detailed data collection—like thread dumps for hanging transactions—configured directly in the intuitive UI.

Persistent Telemetries

Capture scalar values like database operations per minute. Sparklines show trends instantly; full views trace back indefinitely. Data is retained and aggregated over time, never discarded.

Flexible Monitoring

Automatically detect transactions from servlets, EJBs, or RMI. Customize with UI selections, annotations, or API for any method. Correlate server transactions with browser page loads.

How It Works

1. Install and Connect

Launch the pre-activated app on your Mac. Connect to your production JVMs via the simple setup—no agents needed beyond standard integration.

2. Dashboard Overview

View real-time status, telemetries, and call graphs. Spot anomalies across VMs and transactions at a glance.

3. Analyze and Alert

Drill into call trees, database queries, or method samples. Configure triggers for automatic responses like dumps or notifications.

4. Compare and Optimize

Access historical data for comparisons. Escalate to profiling when needed—all from one seamless interface.
